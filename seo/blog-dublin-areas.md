# Dublin area rotation for blog posts

Source: Wikipedia "Category:Places in Dublin (city and county)" list the user provided 2026-08-19.
Purpose: each daily blog post ties in ONE real Dublin area from this list (see
scripts/blog-quality-check.js and the RemoteTrigger routine "Carpet Cleaning Service - Daily Blog Engine").

Rules:
- Pick the first unchecked area, mark it `[x]` once used in a published post.
- If the area already has a /locations/{slug}/ page, link to it naturally in the post body.
- If it doesn't have a page yet, just mention it honestly and naturally (e.g. as an example
  neighbourhood, a place a stain/story could plausibly happen) — never invent a fake link,
  never invent specific claims about that area unless genuinely well-known and true.
- This is about local relevance in blog content, NOT a request to build 160 new
  location pages — that would repeat the exact scaled-content-abuse risk already flagged in
  seo/blog-topic-backlog.md's decision log after the 111-page Kildare/Wicklow rollout.

Total areas: 160 (all 160 now have /locations/{slug}/ pages, built 2026-08-19)
